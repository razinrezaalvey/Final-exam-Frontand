# Courier & Logistics Management Frontend

A complete Vite + React starter project with Tailwind CSS, React Router, Axios,
React Hot Toast, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Create a `.env` file in the project root if you want to configure your FastAPI URL:

```env
VITE_API_URL=http://127.0.0.1:8000
```

The included pages and dashboard components are starter placeholders. Authentication,
role authorization, dashboard functionality, and backend API integration still need
to be implemented.
